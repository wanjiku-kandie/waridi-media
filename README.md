# waridi-media

Public host for Waridi Events social artwork, so scheduling tools can fetch files directly.

Files are referenced by their raw URL, for example:

    https://raw.githubusercontent.com/wanjiku-kandie/waridi-media/main/2026-11/venue-reel.mp4

Folders are named by the month the content runs in.

Nothing client-confidential belongs here: this repository is public.
